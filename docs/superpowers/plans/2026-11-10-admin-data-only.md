# 管理后台数据职责收拢实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans，按任务在当前会话实现，末尾独立审查。

**Goal:** 移除管理后台及服务的研究执行通路，保留外部 Codex 导入与历史数据管理。

**Architecture:** 外部 Codex 通过私有 CLI 登记接收会话，执行研究后提交现有立项包或空报告。网站只校验、存储、提供目录/回执与后续开发管理；维护循环不处理研究队列。

**Tech Stack:** Go、SQLite、现有 HTML 模板与 Python 固定传输工具，不新增依赖。

**Spec:** `docs/superpowers/specs/2026-11-10-admin-data-only-design.md`

## 全局约束

- 已从最新 master `ce489f8` 创建 `codex/admin-data-only`，使用现有隔离工作区。
- Go 命令 CGO_ENABLED=0；单次验证外部截止 570 秒，Go timeout 9m。
- 定时 PAUSED、enabled=false；不调用真实搜索/模型，不改变已有数据/账号/接收授权。
- 既有 JSON 格式、原包幂等、认证/CSRF/Host 与归属保护保持。

## 审查重点

- 旧写 URL 不能绕过隐藏菜单恢复执行；有认证及 CSRF 的请求也应返回 410。
- 已入库旧原包在取消之后仍可原样重试，异字节 409。
- 空报告不得在任务取消、暂停、达标后创建新批次；usage 与任务状态同事务。
- 维护保留清理/备份，但不领取旧队列或恢复等待任务。
- Codex 必须有网页之外的接收会话管理入口，CLI 不得因数据库路径拼错创建新库。
