## 修复与覆盖

- 单候选严格 JSON Schema：拒绝截断、重复键、代码围栏、尾随对象、未知字段、缺字段、错误层级及不存在/重复证据 ID。
- 集合计数：同人多帖、同站子域、模型确认的跨站同人去重；明确条件式意愿与实际消费分别记录；无金额消费仍可满足价格或消费要求。
- 痛点在前帖、付款在跟帖时，在同一用户的相关有效证据组归并，正向/反向顺序结果相同；不同用户不能互借痛点。
- 原文引用/条件必须有出处；缺作者/未知日期、不相关、已满足、广告转述、过期付费、未知币种均有回归用例。
- 立项包核对完整候选、模型记录、目录、任务、逐条标记和引用；更改后不能沿用审查。输出两个输入哈希，用于外部执行端核对冻结原字节。
- CLI 不创建数据库，失败不输出成功 JSON；原始与转义后的疑似凭据均拒绝。
