## 兼容性审查

- 旧后台研究写入口在认证和 CSRF 校验后返回 410；模型设置书签跳转费用页。

- 新空报告只在活动且有缺口的外部立项会话接收，批次、状态和用量同事务完成。等待/暂停不会被报告或每日维护自动恢复。
- task/catalog/projects/receipt 的路由与字段保持；旧模式 should_continue=false。私有 intake CLI 提供外部会话登记、取消和恢复，旧模式只能取消后新建。

设计与代码分别经过独立审查。代码审查没有 Critical/Important 问题；唯一 Minor 是历史回执仍提示等待站内核验，已修改动态提示并增加断言，复核确认闭环。
