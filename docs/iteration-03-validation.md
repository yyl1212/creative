# 迭代 3 验收记录

日期：2026-11-09。范围：网站离线接收/核验闭环，页面仅验收 Mac 桌面浏览器。工作分支 `codex/research-verification` 承接迭代 2，开发前已 fetch/pull 最新 master；本轮没有合并或部署。

## 已实现

- 安全原文抓取、正文哈希、引文/作者/日期绑定；未知来源保持待补证。
- OpenAI Responses 和 DeepSeek Chat 的独立适配，默认禁用，显式模型与备选配置。严格 JSON、拒绝/截断检测、有限网络重试、请求前记录未知费用。
- 网站程序执行资格硬门槛、有效期、重复作者/引文/任务去重；补证版本和已完成需求保护。
- SQLite 租约与旧工作者隔离，逐项检查点、暂停/重试、启动与每日维护；原始材料 30 天和摘要 180 天清理不破坏接收幂等性。
- Mac 管理员需求列表、来源详情、逐项批次结果、版本化重试、按来源和币种划分的费用明细与合计。

## 运行依据

Go 全量测试、构建及 vet 已通过本地执行；每次设置 `CGO_ENABLED=0`，外层 570 秒、Go 测试 9 分钟截止。覆盖真实临时 SQLite、身份与 CSRF 边界、来源地址校验、模型响应异常、租约接管、混合批次、补证竞态、缺口重算、未知费用及重复账单。

`verification-cases.json` 的 30 条自制样本覆盖明确付费、痛点、条件、否定、重复和过期；来源作者/日期绑定及硬规则预期全部通过。语义判断来自独立标注替身，不能将此结果称为真实 OpenAI/DeepSeek 准确率。

隔离 HTTP 预览使用 `localhost:8094`、`127.0.0.1:8094` 与临时库：实际登录、登记执行端、建任务、202 提交与原字节重试、工作循环核验、qualified 回执和 1 合格/2 缺口、需求详情、外部自报费用、来源失败待补证、模型失败暂停且 outcome=null 均通过。全部来源和模型均为自制替身，没有真实外部调用。

Mac Chrome 1510 CSS 像素桌面实测：登录、需求池、证据详情、费用表格、批次重试；页面没有横向溢出，跳到主要内容的键盘操作将焦点移至 main。截图与临时验收报告位于本机 `/private/tmp/creative-iteration3-qa/`。示例需求只存在于临时数据库，公开产品清单仍为 `[]`。
