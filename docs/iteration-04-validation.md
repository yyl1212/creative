## 本地隔离验证

14 个传输测试通过，约 10 秒，使用临时目录和回环 HTTP，无外网、真实候选或模型 API：

| 场景 | 结果 |
| --- | --- |
| 入库后响应丢失，重建客户端再次提交 | 两次 POST 的字节完全一致，仅同一冻结包 |
| 同 batch_id 内容改变 | 拒绝覆盖，旧字节仍可提交 |
| 取消/达标/等待/暂停/规则变化/换任务 | 不发送新 POST；已知回执可查 |
| 原始包到期删除 | 仍能按 batch_id 查询回执 |
| 重定向、代理、非法 origin/ID | 不跟随或失败关闭 |
| 损坏/符号链接/宽权限/重复 JSON/超大包 | 拒绝继续，不发请求 |
| 429 | 保留 Retry-After，不自动重试风暴 |
| 临时接收器自检 | 丢响应后可查回执，只接收一次，到时退出并删凭据 |
